# 恢复说明

## 推荐环境

推荐在同样的 LDNMP/科技 LION 环境中恢复，尤其是目录结构一致时，恢复成功率最高。

默认目标路径：

```bash
/home/web/html/域名
```

## 恢复流程

执行：

```bash
kk restore example.com
```

脚本会列出该域名的备份版本：

```text
1. example.com_20260912_153000.tar.gz
2. example.com_20260910_020000.tar.gz
0. 返回上一级
```

选择编号后，脚本会要求输入 `yes` 二次确认。

如果当前站点目录已存在，脚本会询问是否创建当前状态快照。建议保留默认选择。

## 恢复内容

- 站点文件。
- 数据库。
- Nginx 配置。
- SSL 证书。
- 按备份记录恢复每个站点文件和目录的数字 UID/GID 及权限，不统一修改为固定用户。
- 服务重载或重启。

## 重要限制

- v0.1.6 修复恢复时强制改成 `1000:1000` 的缺陷。旧版备份中的所有者信息仍可读取，不需要为此重新备份。
- 恢复需使用 root。目标环境中 PHP 进程的 UID/GID 应与备份时一致；跨环境用户编号不一致时需要先核对，脚本不会猜测或自动改写。

- 当前版本主要面向同域名恢复。
- 如果更换域名，WordPress 数据库中的链接、序列化数据、插件配置需要额外处理。
- 商业插件的远程授权状态不保证恢复，具体取决于插件厂商。
