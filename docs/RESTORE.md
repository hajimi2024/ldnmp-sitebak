# 恢复说明

## 推荐环境

推荐在同样的 LDNMP/科技 LION 环境中恢复，尤其是目录结构一致时，恢复成功率最高。

默认目标路径：

```bash
/home/web/html/域名
```

## 恢复流程

执行：

```bash
kk restore example.com
```

脚本会列出该域名的备份版本：

```text
1. example.com_20260912_153000.tar.gz
2. example.com_20260910_020000.tar.gz
0. 返回上一级
```

选择编号后，脚本会要求输入 `yes` 二次确认。

如果当前站点目录已存在，脚本会询问是否创建当前状态快照。建议保留默认选择。

## 恢复内容

- 站点文件。
- 数据库。
- Nginx 配置。
- SSL 证书。
- 基础目录权限。
- 服务重载或重启。

## 重要限制

- 当前版本主要面向同域名恢复。
- 如果更换域名，WordPress 数据库中的链接、序列化数据、插件配置需要额外处理。
- 商业插件的远程授权状态不保证恢复，具体取决于插件厂商。
